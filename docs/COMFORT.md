# Comfort rules

Keep the viewer quiet, predictable and adjustable. The [research notes](research/README.md) explain the evidence. These rules are app choices, not rules for everyone with ADHD, autism or low vision.

- Start no sound, flashing, animation or tips without a user action.
- Keep layout, focus and reading position stable. Loading or releasing a preview must not change its sheet size.
- Put words beside main actions. Keep menu group names visible in icons-only mode.
- Use theme resources. Keep focus visible. Colour must not be the only cue.
- Use slate for navigation, sage for adding, sand for editing and clay for removal.
- Keep messages until dismissed or corrected.
- Confirm closing several tabs. Make Cancel the default. Allow closed tabs to reopen.
- Keep keyboard alternatives to pointer actions. Check accessible names and keyboard order.

## Appearance choices

Preferences controls themes, PDF page colours, text size, motion, cursor blinking, toolbar labels and file reload behaviour. Respect desktop choices where available. Keep light and dark alternatives. Focus Mode adds font, spacing and width controls.

Calm uses soft colours. Text targets at least 7:1 contrast, inactive text 4.5:1, and icons and borders 3:1. Calm also caps text contrast at 9.5:1 as a design choice. Offer High contrast for users who need stronger contrast.

PDF page colours can follow the interface or desktop. Keep White and Dark overrides. Ctrl+I switches between the chosen page tone and white. These choices must not change printing.

## Check new controls

Check large text, narrow windows, visible focus, keyboard access and accessible names. Check every theme, reduced motion and icons-only mode. Confirmation buttons must stay reachable. Automated checks do not replace user feedback.
