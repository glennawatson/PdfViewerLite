# Milestones

## Goals

| Goal | Completion check |
|---|---|
| Sign forms with clear, reusable controls | Type, draw or import signatures and initials. Place and adjust them by keyboard. Saved curves and images survive reopening and printing. |
| Reuse signing identities safely | Remember certificates only by choice. Preferences contain no passwords or private keys. |
| Print predictable pages | Preview stays stable while scrolling. Physical duplex output respects the selected edge. |
| Read without visual disruption | Linux pointer-centred zoom has no flicker. |
| Keep interaction efficient | Benchmarks support allocation and timing choices. Rendering and scrolling do not allocate. |
| Navigate with assistive technology | Real screen readers expose usable names, headings and list positions on each desktop. |
| Install trusted releases easily | Shared release checks produce signed desktop packages. Windows includes MSIX made with open-source tools. |

Accessibility work serves ADHD and autistic users first. Improve low-vision access alongside those needs. Keep the [research sources and limits](research/README.md). Each feature needs tests, benchmarks and AOT checks.
