# Autistic web accessibility

Raymaker and colleagues, *Development of the AASPIRE Web Accessibility Guidelines for Autistic Web Users*. [Original PDF](https://pure.port.ac.uk/ws/portalfiles/portal/16733604/Development_of_the_AASPIRE_Web.pdf). [DOI](https://doi.org/10.1089/aut.2018.0020).

Autistic adults helped design and test a healthcare website. The findings support clear language, predictable navigation and user control. PDF pages 9–10 describe varied colour needs. Low contrast may help one person but hinder someone with low vision.

The viewer uses named actions, persistent messages and adjustable colours and text. The study concerns a website. It does not establish one best theme or test this viewer.
