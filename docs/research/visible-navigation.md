# Visible navigation

Pernice and Budiu, *Hamburger Menus and Hidden Navigation Hurt UX Metrics*. [Original report](https://www.nngroup.com/articles/hamburger-menus/).

The study compared six websites with 179 people. Hidden navigation was harder to discover. The viewer keeps Print visible and names secondary action groups.

This is a general web finding, not an ADHD-specific result. It does not mean every action belongs on the toolbar. Groups still need clear names and enough space.
